# ООО «ДеКоМ» — Агентство недвижимости, юридические услуги и оценка в Торопце

Премиальный одностраничный веб-сайт компании ООО «ДеКоМ» (г. Торопец).

## Основные направления деятельности
- 🏠 **Агентство недвижимости**: купля, продажа, обмен квартир, жилых домов, коттеджей и земельных участков в г. Торопец и Торопецком районе. Ипотека и материнский капитал.
- ⚖️ **Юридические услуги**: правовой аудит сделок, проверка объектов на обременения, составление договоров купли-продажи/дарения/аренды, судебная защита.
- 📋 **Оценка собственности**: официальные независимые отчеты об оценке жилья, земли, транспорта и оборудования по стандартам ФСО для Сбербанка и других банков, нотариусов и суда.
